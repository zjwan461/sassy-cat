# 优墨 UI 设计系统：「墨夜 · 琥珀」

> 一次界面审美升级的落地说明。所有颜色、圆角、阴影来自 `src/styles/tokens.css`，
> 基础元素与通用原语在 `src/styles/base.css`。新增页面/组件请只引用变量，不要写死色值。

## 1. 概念

黑猫是「墨」，眼睛是「琥珀」。

界面以近黑的冷墨打底（不是 Tailwind 默认的 `#0f172a` 板岩蓝），
整个产品只用**一种**高饱和暖色作为信号色：琥珀 `#EFA84C`。
其余颜色（青瓷绿、雾蓝、珊瑚、淡紫）饱和度统一压低，只在语义与图表里出现。

这样做的目的：让界面安静下来。旧版的问题是「每个功能都想要一点颜色」——
七种彩色 KPI 图标、导航里一排 emoji、宝蓝/紫渐变按钮——颜色多了，重点就没了。

## 2. 色彩

| 角色 | 变量 | 值 | 用途 |
| --- | --- | --- | --- |
| 画布 | `--ink-950` | `#090C11` | 应用底色 |
| 面板 | `--ink-900` | `#0E1118` | 侧边栏、对话底 |
| 卡片 | `--ink-850`→`--ink-800` | `#12161F`→`#161B25` | 卡片渐变 |
| 抬升 | `--ink-750` | `#1A202B` | hover、选中底 |
| 输入 | `--ink-1000` | `#06080B` | 输入框、代码块 |
| 主色 | `--amber-400` | `#EFA84C` | 主动作、选中、数据强调 |
| 主色渐变 | `--amber-grad` | `#F3BE73→#DE8F35` | 主按钮（配 `--amber-ink` 深色字） |
| 正文 | `--text-1/2/3/4` | `#EBE9E4 / #A9B0BC / #7B8392 / #545C6B` | 四级文字层 |
| 描边 | `--line-1/2/3` | 白色 5.5% / 9% / 14% | 发丝线，保持「墨」的质感 |

语义色：成功 `--jade-400 #7ECBA1`、危险 `--coral-400 #E9776E`、信息 `--azure-400 #8FB6E8`、
特殊来源 `--lilac-400 #C0A6E8`、警示 `--warn-400 #E8C06A`。
图表色板 `--chart-1..6` 是同明度、同灰度的一组，混在一起不打架。

## 3. 排版

- 字体：系统栈优先（`Segoe UI` / `Microsoft YaHei UI` / `PingFang SC`），
  数字一律 `font-variant-numeric: tabular-nums`，统计数字不在刷新时抖动。
- 尺寸：11 / 12 / 12.5 / 13 / 14 / 15 / 18 / 20 / 24 / 26 / 27。
- 标题字距收紧（`-0.012em ~ -0.02em`），中文小标题加宽字距（`0.12em ~ 0.2em`）做分组标签。
- 行高：正文 1.6–1.72，Markdown 1.78，界面标签 1.3。

## 4. 空间与形状

- 间距只用 4 的倍数：`--sp-1..12`。卡片内边距 16–20，卡片间距 14–16。
- 圆角：输入 8、卡片 16、弹窗 16、胶囊 999。不再出现 6/8/9/10/12/14 混用的随手值。
- 阴影是「多层 + 低透明度」：`--shadow-1` 贴地、`--shadow-2` 悬浮、`--shadow-3` 弹窗，
  再叠加 `--hairline`（1px 内高光）——这是深色界面做出「材质感」的关键。

## 5. 动效

- 页面进入：`fadeUp` 380ms（`--ease-out`），路由切换 180ms 淡入淡出。
- 交互反馈：120–200ms，hover 提亮、按下位移 1px。
- 环境动效：服务连接中的状态点呼吸、启动页的琥珀光带。
- 全局尊重 `prefers-reduced-motion`。

## 6. 组件约定

| 原语 | 说明 |
| --- | --- |
| `.ui-btn` | 默认 / `--primary`（琥珀渐变）/ `--ghost` / `--danger` / `--sm` / `--icon` |
| `.ui-card` | 渐变面 + 发丝描边 + 内高光；`--hover` 加抬升 |
| `.ui-input` / `.ui-select` / `.ui-textarea` | 深墨底，琥珀聚焦环 `0 0 0 3px var(--amber-a12)` |
| `.ui-badge` | 胶囊徽章，`--amber/--jade/--coral/--azure/--lilac` 五种语义 |
| `.ui-empty` | 空状态：56px 图标瓦片 + 标题 + 说明 |
| `.ui-dot` | 状态点，`--on/--warn/--off` |
| `AppIcon` | 24×24 线性图标，`name` + `size`，`currentColor` 描边 |

**图标替换 emoji**：导航、按钮、区块标题一律用 `AppIcon`。
emoji 在不同系统上字形与配色不可控，是「像 demo」的主要原因。
emoji 只保留在文案语气里（例如空状态的一句话），不承担控件功能。

## 7. 关键页面

- **App.vue**：216px 侧边栏，按「日常 / 扩展 / 系统」分组；品牌标识是黑猫落在
  浅色「月光瓦片」上（纯黑剪影在深色底上会消失）；底部常驻服务状态点。
  选中态不是整块高饱和色，而是「被点亮」：暖色薄底 + 左侧 2px 指示条 + 图标发光。
- **Dashboard**：4 张主 KPI + 一条知识库摘要（避免 7 张卡片出现 5+2 孤行）；
  图表统一轴线隐藏、虚线网格、琥珀柱 + 雾蓝折线。
- **ChatView**：助手正文不套气泡（更像和一个人说话），用户消息用极淡暖色 + 反向圆角；
  思考/工具/Token 三类折叠面板统一「摘要行 + 旋转箭头」；输入区是一体化书写区。
- **启动页**：黑猫瓦片呼吸 + 琥珀光带，替代转圈 spinner。
- **桌宠气泡**：从纯白改为「月光纸」暖白渐变，与主窗口品牌瓦片同源。
