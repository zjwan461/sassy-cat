# 网易邮箱（163 / 126 / yeah / 188）

个人邮箱与企业邮箱的服务器参数、授权码获取流程、错误码对照。

---

## 一、服务器参数

### 个人免费邮箱（@163.com / @126.com / @yeah.net / @188.com）

四个后缀共用同一套后台，统一用 163 的服务器兼容性最佳，无需按后缀切换。

| 类型 | 服务器地址 | SSL 端口 | 加密 |
|---|---|---|---|
| IMAP 收信 | `imap.163.com` | 993 | SSL |
| SMTP 发信 | `smtp.163.com` | 465 | SSL |
| POP3 收信 | `pop.163.com` | 995 | SSL |

> 126 / yeah / 188 也有专属域名（`imap.126.com`、`imap.yeah.net` 等），
> 但第三方客户端统一填 `imap.163.com` / `smtp.163.com` 最省事，功能完全一致。

### 企业邮箱（域名为自定义域名，服务商为网易企业邮）

| 类型 | 服务器地址 | 端口 |
|---|---|---|
| IMAP 收信 | `imaphz.qiye.163.com` | 993（SSL） |
| SMTP 发信 | `smtphz.qiye.163.com` | 465 / 587 / 994（SSL） |
| POP3 收信 | `pophz.qiye.163.com` | 995（SSL） |

### 不加密端口（不推荐）

IMAP 143 / POP3 110 / SMTP 25。明文传输，仅在排障时临时使用。

## 二、获取客户端授权码（必做，否则 100% 失败）

网易**强制**第三方客户端使用客户端授权码，直接用登录密码会报 `535 Authentication failed`。

1. 登录网易邮箱网页版（`mail.163.com` 或对应后缀）。
2. 顶部 **【设置】** → 左侧 **【POP3/SMTP/IMAP】**。
3. 开启 **【IMAP/SMTP 服务】**（如只发信可另开 POP3/SMTP）。
4. 弹窗中选择「扫码发送短信」或「手动发送短信」，用绑定手机号按提示发送。
5. 点【我已发送】，系统校验通过后展示 **16 位授权码**。

**授权码只显示一次**：关闭弹窗后无法再查看，必须立即复制保存；丢了只能重新生成（旧码作废）。

- 一个授权码可用于多个客户端，无需每个客户端单独生成。
- 授权码区分大小写，输入时不要带空格。
- 网易与其它厂商叫法对照：网易叫「客户端授权码」，腾讯/新浪叫「授权码」，
  搜狐叫「独立密码」，谷歌/微软叫「应用专用密码」——都是同一类东西。

## 三、常见错误码对照

| 报错 | 原因 | 处理 |
|---|---|---|
| `535 Authentication failed` | 用了登录密码，或授权码错误/已失效 | 换成 16 位客户端授权码 |
| `SELECT Unsafe Login. Please contact kefu@188.com` | 未在 `SELECT` 前发送 IMAP `ID` 命令 | 见 troubleshooting.md 第 1 条 |
| `LOGIN Login error user name or password error` | 账号写错（漏了 `@163.com`）或服务未开启 | 检查完整邮箱地址与 IMAP 服务开关 |
| 连接超时 | 993 / 465 端口被防火墙或代理拦截 | 换网络、放行端口，或临时用不加密端口排障 |
| `550 Invalid User` / `554` 发送被拒 | 收件人不存在，或内容被判为垃圾邮件 | 检查收件人，减少链接与敏感词 |

## 四、客户端配置速查

- **Foxmail / 新版 Outlook / 网易邮箱大师**：已支持「一键登录」，
  直接填 `完整邮箱地址 + 16 位授权码` 即可，无需手填服务器。
- **手机自带邮件 App / 老版 Outlook**：手动选择 IMAP，
  按上表填 `imap.163.com:993(SSL)` 与 `smtp.163.com:465(SSL)`，
  密码处填授权码。
- **IMAP 与 POP3 怎么选**：多个设备都要同步、想保留服务器邮件副本 → 选 IMAP；
  只在一台设备收信、想下载后清空服务器 → 选 POP3。现代场景一律推荐 IMAP。
