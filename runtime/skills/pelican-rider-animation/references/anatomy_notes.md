# 鹈鹕解剖速查（画之前看一眼）

## 为什么鹈鹕难画

它的可识别性**几乎全部集中在喙和喉囊上**。身体和别的白色水鸟差不多，
脖子和天鹅/白鹭像，翅膀和海鸥像。所以画错了喙 = 整体失败。

## 关键尺寸关系（按头长为 1 个单位）

| 部位 | 相对头长的比例 | 说明 |
|---|---|---|
| 喙长 | 1.6 ~ 2.2 | **必须比头长**，这是最容易画短的地方 |
| 头长 | 1.0 | 小而圆 |
| 脖长 | 1.2 ~ 1.8 | S 形，有自然弯曲 |
| 身体长 | 2.0 ~ 2.5 | 椭圆，肚子鼓 |
| 喉囊下垂深度 | 0.5 ~ 0.8 | 从喙下缘往下垂 |

## 喙的几何

```
        上喙：细长、笔直、末端有向下的 1px 小钩
        ─────────────────────────────╲
   头 ●╱                            ╲
        ╲░░░░░░░░░░░░░░░░░░░░░░░░╱
         ╲░ 喉囊：从喙根部开始，向后下方鼓出，░
          ╲░ 在喙尖处收拢，整体像个吊床/口袋   ░
           ╲░░░░░░░░░░░░░░░░░░░░░░░░░░░░╱
```

- 上喙与下喙（喉囊上缘）在喙尖汇合
- 喉囊在**根部**最宽最深，向喙尖收窄
- 喉囊上常画几条放射状暗纹，暗示它可以撑开
- 颜色：上喙偏亮橙（`#f5a623`），喉囊更深更饱和（`#e8890c`）

## 常见画法错误

| 错误 | 后果 |
|---|---|
| 喙长 ≈ 头长 | 看起来是鸭子 |
| 喙是完全笔直的锥形，没有喉囊 | 看起来是海鸥/鹤 |
| 喉囊贴在喙上像一层膜 | 失去体积感，看不出是"袋" |
| 脖子画成直筒 | 失去水鸟气质，变企鹅 |
| 身体太瘦 | 鹈鹕是重型水鸟，应该敦实 |
| 喙朝正前方平伸 | 俯视/正面角度下喙会显得短；侧面视图最能体现鹈鹕特征 |

## 加分但别过头的细节

- 围巾/帽子：增加"在骑车"的故事感，但别遮住喙和喉囊
- 喉囊放条小鱼尾：彩蛋，呼应"野餐去"的设定，注意别画太明显
- 出汗/速度线：冲刺时才出现

**注意**：所有配饰都不能盖住喙和喉囊。这两个部位是识别度的全部来源。
