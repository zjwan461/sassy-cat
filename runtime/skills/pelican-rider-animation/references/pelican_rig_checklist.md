# 骑乘类动画 · 交付前核对表

## 一、结构自洽

- [ ] 两个轮子的圆心都在 `GROUND - R` 这条水平线上
- [ ] 两个轮子与地面相切（圆心 y + 半径 = GROUND），不悬空也不陷地
- [ ] 后花鼓、五通、头管下端连成三角形车架，没有散件
- [ ] 座垫在五通的后上方，不是正上方
- [ ] 车把在头管顶端，且比座垫略前、略低或等高
- [ ] 传动比合理：齿盘半径 : 飞轮半径 ≈ 2.5~3

## 二、骑手贴车

- [ ] 身体下缘压在座垫上，中间无缝
- [ ] 髋关节位置在座垫附近偏前
- [ ] 脚严格落在踏板位置上（不是"大概在附近"）
- [ ] 远侧曲柄自动偏移 180°，双踏板不同相位
- [ ] 翅尖搭在把套上，位置与 `GRIP` 常量一致
- [ ] 膝盖朝向正确（前上方），不是往后反折

## 三、鹈鹕识别度

- [ ] 喙又长又直，长度接近甚至超过头长
- [ ] 喙尖有向下的细微小钩
- [ ] 喉囊挂在喙下方，明显下垂，颜色比喙深
- [ ] 脖子是 S 形曲线，不是直筒
- [ ] 眼睛在喙根稍后方
- [ ] 整体配色：白/米白身体 + 橙黄喙囊（不是全白或全黄）

**自测**：把图截出来给没看过提示词的人看，能一眼说出"这是鹈鹕"才算过。

## 四、运动逻辑

- [ ] 轮子转角 = 累计位移 / 半径（纯滚动，不打滑）
- [ ] 踏频与轮速通过传动比绑定
- [ ] 踏板位置由曲柄角实时计算，不是独立动画
- [ ] 腿的 IK 每帧重解，膝盖位置随踏板实时变化
- [ ] 背景视差各层速度不同，且都从位移派生
- [ ] 车身有轻微上下颠簸，与踏频同频

## 五、健壮性

- [ ] `dt` 被夹住（`Math.min(dt, 0.05)`），切标签页回来不瞬移
- [ ] `resize` 时按 `devicePixelRatio` 重设画布尺寸
- [ ] 所有 `Math.acos` 的入参都夹到 `[-1, 1]`
- [ ] 所有除法都防了零分母
- [ ] 暂停时 `dt` 清零，恢复后不跳帧
- [ ] 交互目标（`pointerdown` / `keydown`）注册在 `window` 或 `document` 上，不要只挂在 canvas 上

## 六、验证留痕

- [ ] `node --check` 通过
- [ ] `smoke_test.py` 退出码 0，NaN 计数为 0
- [ ] `check_rig_geometry.py` 退出码 0
- [ ] 汇报里写出了实测数值，不是"应该没问题"
