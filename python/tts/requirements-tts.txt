# GPT-SoVITS inference dependencies (in-process integration, Python 3.11)
#
# These are the *Python packages* the vendored inference code needs.
# (Pruning vendor/gpt-sovits removed training/WebUI/export *source*, but the
#  third-party packages below are still required.)
#
# STEP 1 - install PyTorch first, from the cu128 index.
#          PyPI wheels are CPU-only and will fail on RTX 50 series (sm_120).
#
#     pip install --index-url https://download.pytorch.org/whl/cu128 torch torchaudio
#
#     python -c "import torch;print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_arch_list())"
#
#          The arch list must contain sm_120.
#
# STEP 2 - install this file:
#
#     pip install -r python/tts/requirements-tts.txt
#
# STEP 3 - non-pip data resources (NOT installable via pip, see docs section 8.1):
#          * pyopenjtalk >= 0.4 does NOT bundle its dictionary. Without it the
#            Japanese frontend tries to download 102 MB at first use and HANGS
#            on offline/proxied machines. Ship open_jtalk_dic_utf_8-1.11 or set
#            OPEN_JTALK_DICT_DIR.
#          * g2p_en needs nltk data: taggers/averaged_perceptron_tagger(_eng)
#            and corpora/cmudict. Missing data makes nltk download silently.
#          Both are pre-checked at runtime by the adapter; it skips the language
#          with a warning instead of hanging.
#
# NOTE on version pins: numpy<2.0 and transformers<=4.50 are required by the
# upstream inference code. If your app already uses sentence-transformers>=6
# (which needs transformers>=5), the two cannot share one environment - verify
# RAG before/after, or fall back to a separate process for TTS.
